# 游戏咨询助手 
通过fastapi and 智谱，做了一个网页对话助手，可以当作 你想要获取某个游戏论坛的游戏信息使用。

agent 是 用于创建AGENT 

toolmodle 用于创建 工具 

main  是用来运行的页面  在运行时可以先询问 你想要获得什么样的信息 
使用方法：想要运行的时候就打开 main 文件夹 点击运行 可以找到下面的运行结果 然后点击进入页面就可以


再使用前 请先创建.env 文件 然后写入 API_KEY=你的密钥 （抱歉 这个是使用的智谱 所以需要智谱的密钥 不过你也可以更改一下）
