# AGET-model-ZHIPU
通过智谱提供的工具来扒取 页面数据 用于 获取当前页面游戏的信息数据，可以当作 你想要获取某个游戏论坛的数据使用。

zhu  是 用于创建AGENT 

toolmodle 用于创建 工具 

main  是用来运行的页面  在运行时可以先询问 你想要获得什么样的信息 

再使用前 请先创建.env 文件 然后写入 API_KEY=你的密钥 （抱歉 这个是使用的智谱 所以需要智谱的密钥 不过你也可以更改一下）

这只是我在查看智谱的使用文档时 正好我在学习python request ，所以突发奇想 感觉还挺好用的，就做了一个。


使用方法  

在main  中运行  然后输入你想知道的论坛 地址 比如 www.xxx.cn  然后运行即可   不输入网址也是可以 我设置的默认是 nga
